# 연구 1 중앙 관제 통신 장애 결과 (10/16~17)

가짜 로봇 5대(`fleet_fake`), 조건마다 10회(seed 1~10), 기종 `c2d-standard-8`. 실행 목록은 `runs.txt`(라벨 → Actions run id → GCS 경로 → git sha).
사전 예측은 `../predictions.md`(P1~P3, 10/17 17:12 등록), `../predictions_2.md`(P4·P5).

## 다시 만들기

```bash
cd experiments/research1/central
./fetch.sh                       # data/<라벨>/<반복>/ 에 지표 CSV만 받는다 (gcloud 로그인)
python3 analysis.py data         # 조건별 표, 기준 대비 짝지은 차이(부트스트랩 95% CI, Wilcoxon + Holm)
python3 compare.py data central_bo30_r3 hybrid_bo30_r3   # 두 조건 짝지은 비교
python3 figs.py data figures     # 그림 A·B·C (NanumGothic 글꼴 필요, matplotlib·numpy·scipy)
```

## 그림

| 파일 | 내용 |
| --- | --- |
| `figures/figA_conditions` | 조건별 평균 작업 완료 시간 변화(장애 없음 대비, 같은 seed끼리). 점선 = 급락 기준 +10%. 회색 = 95% CI가 0을 포함. 기준을 넘는 건 25초 작업 + 손실 70%(+18.8%)와 단절 30초 + 멈춤 정책(+21.7%)뿐 |
| `figures/figB_prediction(_wide)` | 예측 vs 실측. (a) 명령을 받기까지 추가 대기 W = r·p/(1−p) (b) 처리량 감소 (T+g0)/(T+g0+W). 검은 점 = 사후 적합(손실 30/50/70%), 흰 기호 = 사전 예측(재전송 0·1번, 25초 작업) |
| `figures/figC_policy(_wide)` | 단절 30초에서 끊긴 로봇의 정책: ① 멈춤 ② 받은 일 계속 ③ 새 일도 스스로(하이브리드, 상한). (a) 끊긴 로봇 완료 작업 (b) 전체 완료 시간 변화 |

`_wide`는 두 단 폭(180 mm), 나머지는 한 단 폭(88 mm)이다.

## 결과 요약

| 조건 (기준 대비) | 완료 시간 변화 [95% CI] | 비고 |
| --- | --- | --- |
| 지연 100/200/500 ms | +0.5% / +0.6% / +0.5% | 차이 없음 |
| 손실 30/50/70% | +1.2% / +2.4% / +6.4% [4.0, 8.7] | 추가 대기 실측 0.38 / 0.98 / 2.29초, 예측 0.43 / 1.00 / 2.33초 |
| 손실 50%, 재전송 0·1번 | 처리량 차이 없음 | 추가 대기 0.93 / 1.03초 (P1 적중). 재배정이 재전송을 대신함 |
| 단절 3/10/30초 (amr_03) | −0.3% / +0.9% / +4.6% [2.4, 6.9] | 30초: amr_03 가동률 94 → 83% |
| 단절 30초 + 멈춤 정책 | **+21.7%** [18.6, 24.8] | amr_03 완료 4.0건(예측 약 4), 전체 36.9건(예측 약 36.5) (P3 적중) |
| 단절 30초 + 하이브리드 | +1.9% | amr_03 가동률 89%. 작업 방송에 장애가 없어 상한 |
| 25초 작업 손실 50/70% | 처리량 −4.5% / −8.9% | 예측 −3.9% / −8.6% (P2 적중). 완료 시간 +18.8% |
| 비포화(30초 간격) 손실 70% | 처리량 변화 없음 | 첫 확인까지 대기 +2.19초 (예측 2.33초) |
| 최신 코드 기준 재측정 | 완료 40.0 vs 40.1건 | 조건마다 다른 코드 버전의 영향 없음 |

중복 실행(같은 작업을 둘 이상의 로봇이 수행)은 모든 조건에서 0건.

## 주의

- 장애는 서버 → 로봇 한 방향, 앱 계층에서 메시지를 버린다(DDS RELIABLE 재전송 전 손실이 아님). 손실은 메시지마다 독립
- 가짜 로봇은 교통 통제(구역 허가)가 없다. 하이브리드는 작업 방송·모드 알림에 장애가 없어 상한
- 손실 30/50/70%의 식 일치는 사후 적합. 사전 예측 검증은 재전송 0·1번, 25초 작업, 멈춤 정책
- 재전송 횟수가 다른 조건끼리 Ack 왕복 P95를 비교하지 않는다 (실패한 명령은 기록에서 빠진다)
