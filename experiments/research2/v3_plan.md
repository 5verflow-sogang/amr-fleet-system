# 연구 2 v3 본 실험 사전 등록

결과를 보기 전에 커밋한다. 실행 `scripts/run_v3_main.sh`, 판정 `scripts/judge_v3_main.py`.

## 1. 목적

적재 질량을 관측하는 RL 로컬 플래너(제안)가 질량을 보지 않는 플래너(R2)보다
질량에 따라 속도를 더 맞추는지, 그리고 그 정보로 가벼울 때 더 빨리 가는지 확인한다.
정책 사이 비교는 시드마다 편차가 커서(같은 충돌률에서 0 kg 시간 14~24 s) 효율 차이를 가리지 못했다(확인 실험 C1·C2 불통과).
그래서 주 지표는 **같은 제안 정책에서 질량 정보만 바꾼 비교**(정보 실험 I1~I3)로 하고, 정책 사이 비교는 질량 의존(M1)과 보조 지표로 둔다.

## 2. 설정

| 항목 | 값 |
| --- | --- |
| 학습 설정 | `config/env_v3_final.toml` = v2 채택안 ab에 `[ppo] clip_reward = 100.0` 한 줄 추가 |
| 보상 | G (질량 없음). 충돌 −300 − 40·v, 시간 초과 −75, 도착 +100, 진행 5/m, 시간 −0.1/스텝, 지나침 −12.5/m |
| 학습 시나리오 | 돌발 장애물 확률 0.9 (ab) |
| 보상 자르기 | VecNormalize 기본값 10이면 정규화한 충돌 벌점이 −10에서 잘린다. 100으로 풀어 벌점이 실제로 들어가게 한다 |
| 학습 | PPO 300만 스텝, 10만 스텝마다 검증, best 체크포인트로 평가. 제약(라그랑지안) 없음 |
| 비교군 | proposed(질량 무작위·관측, 20% 판은 가림, 제동 능력 비율), R2(질량 무작위·관측 안 함), R1(0 kg 고정 학습·관측 안 함) |
| 시드 | **40~59** (20개). 본 실험 범위 0~99 중 v1 0~19, v2 20~39(예약, 본 실험 안 함), v3 40~59 |
| 평가 | `config/env_v0.toml` 시나리오, 질량 0·2·10·25 kg(학습)·15·30 kg(처음 봄) × S1·S2 × 200회, 평가 목록 = 학습 시드 |
| 정보 조건 | 제안: exact(정확)·unknown(모름)·told0(0 kg이라고 알림)·told25(25 kg이라고 알림). R1·R2는 질량을 보지 않아 exact만 |
| 반응 곡선 | `probe_v3_mass_response.py`: 같은 상태에서 질량 칸만 바꿨을 때의 속도 → 질량 적응도(오라클 감속 대비) |

학습 전 점검(못 넘으면 시작하지 않음): 커밋 안 된 변경 없음, pytest, `check_reward.py`(안전 순항 속도가 최적),
`check_reward_traps.py`(지나치기·기어가기·안 가기가 정상 주행보다 낮음, 목록 398·399), 규칙 정책 mass_aware 충돌 0건(학습 설정, 목록 398, 800판).

## 3. 정의

- 충돌률: S1에서 돌발 장애물이 나타난 판 중 충돌 비율
- 짝지은 시간 차: 같은 시나리오(scenario, scenario_seed)·같은 질량에서 두 쪽 모두 성공한 판끼리 도착 시간 차의 평균
- 자기 성공 판 시간: 그 비교군이 성공한 판의 평균 도착 시간
- 시드마다 계산하고, 시드 평균의 95% CI는 시드 부트스트랩(4000회, 난수 0)
- 무너진 시드: 학습 질량에서 성공 < 85% 또는 시간 초과 > 10%

## 4. 판정 기준

| 구분 | 기호 | 지표 | 통과 |
| --- | --- | --- | --- |
| 주 지표 | I1 | 0 kg 도착 시간, 제안 exact − unknown (짝지음) | 95% CI 상한 < 0 |
| 주 지표 | I2 | 학습 질량 전체 충돌률, 제안 exact − unknown | 95% CI 상한 ≤ +2%p |
| 정보 의존 | I3 | 25 kg 충돌률, 제안 told0 − exact | 95% CI 하한 > 0 |
| 질량 의존 | M1 | (25 kg − 0 kg 자기 성공 판 시간), 제안 exact − R2 | 95% CI 하한 > 0 |
| 해석 기준 | I0 | 0 kg 도착 시간, 제안 unknown − R2 (짝지음) | CI 하한 > 0이면 I1은 "모름 조건을 덜 연습한 영향이 섞인 상한"으로 쓴다 |
| 보조 | C1 | 0 kg 자기 성공 판 시간, 제안 exact − R2 | 95% CI 상한 < 0 |
| 보조 | C2 | 학습 질량 전체 충돌률, 제안 exact − R2 | 95% CI 상한 ≤ +2%p |
| 보고 | — | 10·25 kg 충돌률 제안 exact − R1, 처음 보는 질량 15·30 kg, 질량 적응도, 비교군별 무너진 시드 수 | 판정 없음 |

- 무너진 시드는 빼지 않는다. 제안의 무너진 시드를 뺀 I1·I2·I3 민감도 분석을 덧붙인다.
- 판정 스크립트는 정보 실험 데이터(시드 330~369)로 미리 검증했다: I1 −1.28 s, I2 −0.92%p, I3 +7.61%p, M1 +1.30 s, I0 +0.69 s, C1 −0.58 s, C2 +0.88%p, 적응도 61%.
  이 값은 튜닝 시드에서 나온 것이고, 판정은 새 시드 40~59로만 한다.
- 이 학습 설정(ab + 자르기 100)은 튜닝 단계에서 학습해 본 적이 없다. 벌점 −300 단계(pen300)에서는 제안 20개 중 2개가 무너졌다.

## 5. DWA 비교 (나중에)

DWA(B1·B2)는 학습이 없으므로, 이진의 코어 수정 뒤 같은 목록 40~59, 같은 평가 설정(`config/env_v0.toml`,

## 7. 계획 변경: DWA 비교를 목록 20~39에서도 (10/18 실행 뒤 추가)

**무엇이 바뀌었나**: 5절은 DWA를 목록 40~59로 평가하기로 했지만, 민지가 v2 계획(`v2_plan.md`)대로 목록 20~39로 먼저 평가했다
(커밋 `e3ecf7a`, #228 코어 수정 + #234 `max_v` 1.248 위, 둘 다 미머지. 10/18 13:28~19:30, 민지 Mac, 오류 0건).
RL을 다시 학습하지 않고, **v3 본 실험 정책 60개를 목록 20~39로 추가 평가**해 같은 판끼리 짝지었다.

- 다시 학습하지 않은 이유: 시드 20~39로 새로 학습하면 본 실험이 둘이 되고, 결과를 본 뒤 어느 쪽을 쓸지 고르게 된다. 짝짓기는 학습 시드가 아니라 평가 목록으로 성립하고(DWA는 학습이 없다), 목록 20~39는 v2 본 실험이 취소돼 어떤 RL 학습·튜닝에도 쓰이지 않았다
- 대응: 정책 시드 s → 목록 s − 20 (시드 40 → 목록 20 … 59 → 39). 평가 설정은 DWA와 같게 `config/env_v0.toml`, 학습 질량 0·2·10·25 kg × S1·S2 × 100회, 제안은 exact·unknown
