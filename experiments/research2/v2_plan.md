# 연구 2 v2 사전 등록

v2는 본 실험 v1(10/16, 최종 평가 목록 0~19) 결과를 본 뒤 설정을 바꾸는 **후속 실험**이다. 원고에는 v1과 v2를 둘 다 적는다. 목록 0~19로 다시 평가하지 않는다.

- **1절(튜닝)은 10/17 팀 합의를 옮긴 것이다.** 이 파일이 리포에 들어간 커밋 시각이 등록 시각이다. 바꾸려면 튜닝을 돌리기 전에 말하고, 결과를 본 뒤에는 바꾸지 않는다
- 2절(본 실험)은 10/18 채택 뒤 같은 파일에 더한다

- 후보마다 제안·R2를 둘 다 학습한다 (트랙당 3설정 × 2비교군 × 시드 10 = 60번). R1은 최종 고른 설정에서만 시드 5개로 무너지지 않는지 확인한다
- v2 본 실험(RL 전부)은 하연 Mac 한 대에서 돌린다. DWA 재평가는 민지 Mac

### 1-3. 튜닝 평가와 채택 규칙

평가는 학습 질량 0·2·10·25 kg, 질량 정보 정확, 질량마다 S1 200 + S2 200이다. 15·30 kg은 보지 않는다(H3 최종 평가용).

후보는 아래 세 조건을 **모두** 만족해야 채택한다. 비교는 시드 10개 평균이고 기준은 같은 기계의 기준선이다.

1. 제안의 25 kg 충돌률(돌발 장애물 출현 분모)이 **2%p 이상** 줄어든다
2. 제안의 학습 질량 전체 시간 초과율 증가가 **+5%p 이내**
3. R2의 학습 질량 전체 성공률 하락이 **5%p 이내** (R2가 무너지면 비교가 깨진다)

- 한 트랙에서 둘 다 통과하면 25 kg 충돌률이 낮은 쪽. 둘 다 탈락이면 그 트랙은 v1 설정을 유지한다
- 95% CI와 감속 폭(0 → 25 kg 속도)은 같이 보고하되 채택 조건에는 넣지 않는다
- **합치기**: A·B가 둘 다 채택되면 두 채택안을 합친 후보를 연우 Mac에서 시드 220~229로 돌린다(1-1절, 실행 전에 Windows에서 바꿈)(기준선도 같은 기계·시드). 하연 Mac은 그날 밤 본 실험에 비워 둔다. 합친 후보가 세 조건을 통과하고 개선 폭(자기 기준선 대비 25 kg 충돌 감소)이 A·B 단독보다 크면 합친 것을, 아니면 개선 폭이 큰 단독안을 고른다

### 1-6. 사후 기록 (등록 규칙에서 벗어난 것)

- **예비 시드 299**: 트랙 A(10/17 00:35)·합친 후보(12:22) 시험 실행(2만 스텝, 결과 버림)에 썼다. 1-1절은 "쓰기 전에 알린다"인데 사후에 알렸다 (연우)
- **시드 210~219 재사용**: v2와 별개인 탐색 실험 1·2(질량 정보 값어치, #221)가 트랙 B 튜닝 시드 210~219를 다시 썼다. 최종 평가 목록(0~39)과 겹치지 않아 v2 판정·본 실험에는 영향이 없다 (하연)
- **무너진 시드** (학습 질량 성공 < 85% 또는 시간 초과 > 10%): A2 R2 s208(성공 84.9%, 시간 초과 10.4%), ab R2 s225(84.4%, 11.2%). 각 10개 중 1개, R2만이고 제안·A1·기준선은 0개다. 판정은 시드 10개 평균이라 그대로다. 2절 무너짐 규칙의 근거로 쓴다

### 1-7. 2절에 넘길 것

- 위 무너진 시드 기준(성공 < 85% 또는 시간 초과 > 10%)을 v2 본 실험의 무너짐 규칙 후보로
- 탐색 실험(#221) 함정 점검에서 A2·ab는 "지나치기 − 기어가기" 비용 차이가 G의 3배다(지나침 벌점을 안 키움). v2 본 실험에서 시드별 지나침·시간 초과를 **보고 항목**으로 낸다 (판정 조건 아님)
- 탐색 실험에서 G를 더 학습(3M → 4.5M)하자 제안 − R2가 벌어졌다는 사후 관찰이 있다. v2 학습 스텝을 바꾸려면 2절 등록 **전에** 정하고 "탐색 실험을 보고 정했다"고 적는다. 안 바꾸면 3M 그대로
